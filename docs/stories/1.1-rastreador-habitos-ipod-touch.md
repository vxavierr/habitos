## Objetivo

App estático, offline após instalação, para marcar hábitos diários com um toque num iPod touch 6 (iOS 12, sem jailbreak).

## Acceptance criteria

1. Três áreas: Hoje, Histórico, Ajustes.
2. Criar, renomear, marcar, desmarcar, arquivar. Arquivar preserva histórico.
3. Começa vazio; exemplos só se o usuário pedir, e rotulados como opcionais.
4. IndexedDB com um check-in por hábito/data; falha de escrita visível.
5. Datas locais `YYYY-MM-DD`; “hoje” recalcula ao reabrir/voltar.
6. Service worker clássico; “offline” só com cache essencial + página controlada.
7. Backup JSON versionado; import substitui com confirmação ou recusa sem mexer no banco.
8. Layout utilizável em 320×568 CSS px; alvos ≥ 44 px; sem bloquear zoom.
9. Sem CDN, login, backend, push, IA, App Store.
